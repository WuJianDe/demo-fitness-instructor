# Demo Fitness Instructor

Monorepo for a fitness instructor brand site.

## Projects

- `frontend/`: public-facing website built with Vue 3, Vite, TypeScript, and `vite-ssg`

## Git Workflow

This repo follows the rules documented in `AGENTS.md`.

- Default development branch: `develop`
- Release branch: `main`
- Feature branches: `feat/<scope>/<name>`
- Fix branches: `fix/<scope>/<name>`

## Current Frontend Direction

The current homepage is a premium, editorial-style landing page for a Taipei-based female fitness coach brand.
It includes:

- Hero section with full-bleed coach imagery
- Philosophy / brand positioning section
- Signature training programs
- Training blueprint section
- Consultation call-to-action
- Scroll-triggered reveal animations powered by GSAP
