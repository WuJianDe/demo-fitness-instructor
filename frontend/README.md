# Frontend

Public-facing website scaffold for the fitness instructor project.

## Stack

- Vue 3 with `<script setup lang="ts">`
- Vite + `vite-ssg`
- Vue Router
- Pinia
- `@vueuse/head`
- Axios
- SCSS

## Commands

Run all commands from `frontend/`.

```bash
npm install
npm run dev
npm run build
npm run preview
npm run type-check
npm run lint
npm run lint:fix
npm run format
npm run format:check
```
